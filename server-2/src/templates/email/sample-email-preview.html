📧 CA-Flow Email Notification Samples

Note: These are visual representations of the email templates. Actual emails are sent using HTML email standards with inline CSS for maximum compatibility across email clients.

💰 Payment Notification

Sent when a client makes a payment or when payment fails.

High Priority
Features:
  • Amount display with ₹ formatting
  • Client name
  • Status badge (success/failure)
  • Color-coded based on status
  • Action button to view details

💬 New Conversation

Sent when a new conversation thread is created.

Normal Priority
Features:
  • Conversation subject
  • Sender information
  • Icon-based indicators
  • Action button to view conversation

📨 New Message

Sent when a new message is received in a conversation.

Normal Priority
Features:
  • Conversation subject
  • Sender information
  • Message preview
  • Action button to view message

📄 Document Uploaded

Sent when documents are uploaded in a conversation.

Low Priority (No Email)
Features:
  • Document name or count
  • Uploader information
  • Visual document icon
  • Action button to view documents

✅ Subscription Activated

Sent when a subscription is successfully activated.

High Priority
Features:
  • Plan name
  • Amount and billing info
  • Next billing date
  • Action button to view subscription

❌ Subscription Payment Failed

Sent when subscription payment fails.

Urgent Priority
Features:
  • Plan name
  • Amount information
  • Urgent styling
  • Action button to update payment

🎉 Client First Login

Sent when a client logs in for the first time.

Normal Priority
Features:
  • Client name
  • Login timestamp
  • Celebration styling
  • Action button to view client

👤 Client Login

Sent when a client logs in (regular).

Low Priority (No Email)
Features:
  • Client name
  • Login timestamp
  • Simple notification
  • Action button to view client

Email Priority Rules: Emails are automatically sent for Urgent, High, and Normal priority notifications. Low priority notifications do not trigger emails to reduce inbox clutter.

📱 Responsive Design

All email templates are fully responsive and tested on:

  • Desktop: Gmail, Outlook, Apple Mail, Thunderbird
  • Mobile: Gmail (iOS/Android), Apple Mail (iOS), Outlook (iOS/Android)
  • Webmail: Gmail, Outlook.com, Yahoo Mail, ProtonMail
